Student Assignment Tracker (IMS566) - Improved Version

Files:
- index.html (Login)
- register.html (Register)
- menu.html (Menu)
- dashboard.html (Dashboard - dynamic stats)
- assignment.html (Data View 1 - CRUD)
- analytics.html (Data View 2 - analytics + overdue list)
- sidebar.css (shared sidebar styles)
- app.js (shared JS helpers: auth, greeting, assignments)

How to run:
- Open index.html in Chrome (or deploy on GitHub Pages)
- Register a new user at register.html, then log in via index.html

Notes:
- Data persists in your browser (stays after refresh).
- Dashboard + Analytics read data from the Assignments page.
